# チャポポ救出作戦 — 4地点MVP

公開サイトは `./mvp/` です。トップURLから自動で移動します。8地点版から進捗保存キーを分離しています。

ルート：歌舞伎町タワー2F（シネシティ広場側）→タイトーステーション新宿東口店4F→ビックカメラ新宿東口店1F西側エレベーター前→歌舞伎町タワー2F（西武新宿駅側）。ST3で1時間無料券を適用し、実レンタルを自己申告。施設許諾・設置・営業時間・無料券の確定は開催前に必要です。

詳細は [MVP版README](./mvp/README.md)。正答は運営テスト表示にあります。アンケートは端末内保存のみで、送信・集計は行いません。動画制作・正式キャラクター素材の承認は別途必要です。

GitHub Pages：Settings → Pages → Deploy from a branch → main / root。静的ファイルのみでバックエンド不要。サブパス対応。
