現在は指定ルートを入力済みです：東急歌舞伎町タワー（シネシティ広場側）→塔外自販機→GiGO 新宿歌舞伎町→タイトーステーション新宿東口店4F→ビックカメラ新宿東口店→ルミネエスト新宿→西武新宿駅北口→東急歌舞伎町タワー（西武新宿駅側）。`config.js` のみを編集すれば、8地点の施設名・住所・Google Maps URL・営業時間・クーポンコード・アンケートURLを置換できます。回答、ヒント、進行は `localStorage` に保存され、サーバー/APIは不要です。

## GitHub Pages 公開手順

1. この `chargespot-shinjuku` フォルダの中身をGitHubリポジトリのルートへ置く。
2. GitHubの **Settings → Pages** で **Deploy from a branch** を選び、`main` / `/(root)` を指定して保存。
3. 表示された `https://<account>.github.io/<repo>/` をスマホで開く。全参照は相対パスのため、リポジトリ名付きURLでも動作します。
4. 公開直前に `config.js`、動画 `assets/st1.mp4`〜`st8.mp4`、無料券、アンケートURL、会場情報を確定する。

## 運営テスト

- 正答：`MONITOR` / `365` / `NORTH` / `LOCK` / ST5で「レンタルできた」→`SAFE` / `RECOVER` / `TOWER` / `MONITOR DETECT LOCK RECOVER`
