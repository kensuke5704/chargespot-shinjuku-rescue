# 現行版：物語・移動・謎解きの分離（2026年10月2日）

施設名を大きく示す移動画面 → 「到着した」 → 大きな昼景イラストと全文ストーリー → 「謎を解く」 → 答え入力 → 正解・続きの物語・ChargeSPOTの安全紹介 → 次の目的地。

- 謎の解法説明、事前・事後アンケート、「解説を読み終える」ボタンを削除。
- 到着時と正解後で別の画像ファイルを使用。`sceneArt` / `outcomeArt` / `endingArt` で対応を管理。既存の生成イラスト5枚を再構成し、新規生成は行っていない。
- 横長のシーンから白い読書領域へ重なる構成。モバイルは一列、台詞は本文と別の面で強調。過剰な自動演出を避け、画面切り替えのみ短い遷移を使用。動きを抑える設定に対応。
- `localStorage` の既存進捗キーを維持。保存済み正解は引き継ぎ、未到着の次地点には移動画面を表示。
- `flow.test.cjs` は4地点の到着ゲート、画像切り替え、レンタル条件、正誤、正解画面からの直接移動、再読込、ログ、リセットを検証。
- 公開更新ファイル：`index.html`, `app.js`, `config.js`, `mission.css`, `flow.test.cjs`, `README.md`。以前の版の記録は上に残しているが、本節が現在の仕様。
