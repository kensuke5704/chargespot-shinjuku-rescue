# 4地点MVP版

## 現行版：日中の街歩きSF救出作戦（2026年10月2日）

夜景コンセプトを撤回。昼下がりの新宿でチャポポを救う物語へ変更しました。白系背景・濃いゴシック体・青緑アクセントの明るいUIを全画面で統一。本文17px、行間約2、セリフを色と太さ・字下げで区別。自動送りや文字が1文字ずつ出る演出はありません。

到着時・正解後の物語を段落単位で表示し、「前へ」「物語の続きを読む」で手動操作。最後に「謎に進む」で入力欄を表示。解説後も物語を読み進めてから次の地点へ進みます。全文を読む折りたたみ表示あり。現在の段落・読了状態を端末保存し、再読み込み・捜査ログから戻ると引き継ぎます。

場面画像：ST1/導入＝day-trace.jpg、ST2＝day-lock.jpg、ST3＝day-rental.jpg、ST4到着＝day-final.jpg、ST4正解/ゴール＝day-ending.jpg。config.jsのsceneArt / endingArtで変更できます。元の夜景素材は履歴として保管し、現行サイトでは使いません。チャポポの公式画像は生成せず、救難信号・光の演出で表現。バッテリーとステーションは架空の物語用の図で、製品仕様や設置場所を示すものではありません。

生成：組み込みimage_genを使用、同じガルルのデザインを参照し、晴れた昼の新宿、手描きアニメ調、文字・ロゴ・公式キャラクターなしで5場面を個別制作。完全なプロンプトはday-illustration-prompts.json。各Web用JPEGはこのREADMEと同じフォルダに格納。

UI参考：SCRAP『JACKEYES』 https://realdgame.jp/s/jackeyes/ の短い文・段落の余白・絵と物語の組み合わせ、スパイク・チュンソフト『超探偵事件簿 レインコード』 https://www.spike-chunsoft.co.jp/pages/raincode/ の都市とキャラクターで場面を伝える構成。2026年10月2日閲覧。素材とコードは転載していません。明朝体ではなく、本イベントのSF世界観に合わせたゴシック体を使用しています。

公開に必要なファイル：index.html、app.js、config.js、mission.css、day-trace.jpg、day-lock.jpg、day-rental.jpg、day-final.jpg、day-ending.jpg。すべてmvp/へ配置。旧進捗を引き継ぎ、謎の答えや安全管理の根拠は変更していません。node flow.test.cjsで4地点の進行・物語読了・解説・レンタルゲートを検証。

## 物語・解説の更新（2026年10月2日）

ルートタブを削除。現在地点の地図リンクはミッション内に残しています。プロローグと各地点の到着時・正解後の物語を追加しました。正解送信後は必ず専用画面に進み、「正解」「謎の解説」「答えに関連するChargeSPOTの安全管理」「物語の続き」を表示。参加者が次へを押すまで進行しません。再読み込みでも解説画面を維持します。物語・謎の解説はconfig.jsのprologue / narrativeで編集可能です。ブラウザで365を送信し、解説表示・再読み込み維持を確認。flow.test.cjsで全4正答の解説とレンタルゲートを検証。

## UI刷新（2026年10月2日）

表示はmission.cssとapp.js。既存の8地点版styles.cssは変更していません。導入、ミッション、正解後の説明、ゴール、ルート、捜査ログを統一。設定ダイアログにリセットと運営テストを移しました。免責の段落と重複説明は画面から削除。無料時間超過・返却確認と歩きスマホ防止は実操作に必要な案内として残しています。

進捗保存キーは従来と同じ。既存参加者の進捗と正解後の説明状態を引き継ぎます。script/CSSのURLに版識別を付けています。

参考UI（独自実装、素材は転載なし）：SCRAPの新宿謎解き街歩き https://mysterycircus.jp/s/kumakeynazo/ の大きなキーアート、Ingress https://ingress.com/en の暗い背景と抑えた操作階層。いずれも2026年10月1日から2日に閲覧。

生成イラスト：shinjuku-night.jpg（Web用654KB）とshinjuku-night.png（原本）。組み込みImageGenで生成。プロンプト：新宿夜景、屋上で抽象的なエネルギーを持つオリジナルのオオカミ型エイリアン「ガルル」、ネイビーと控えめなシアン、手描きの建築線とアニメ調、文字・ロゴ・公式チャポポ・実製品なし。これは架空の物語の背景であり、正確な道案内には地図リンクを使用します。

検証：node flow.test.cjs。4地点の正誤、レンタル制限、正解後説明、再読み込み、次へ、ゴール、ログ、ルート、リセット、旧進捗の引き継ぎ。390pxスマホ幅とデスクトップ幅で表示確認。

正答入力後は「正解！」と関連するChargeSPOTの説明を表示し、参加者が「次のステーションへ進む」（ST4は「ゴールへ進む」）を押して進みます。説明画面も保存され、再読み込みしても飛ばされません。ST1：365日IoT監視、ST2：異常時の貸出ロック・給電遮断、ST3：回収と最長3年の管理運用、ST4：安全管理の振り返りと今後の利用提案。説明はconfig.jsのpromotionsで編集できます。公式出典 https://chargespot.jp/topics/2444/ を2026年10月1日に再確認。リスクゼロを保証する表現は使用していません。

START：歌舞伎町タワー2F（シネシティ広場側） → タイトーステーション新宿東口店4F → ビックカメラ新宿東口店1F（西側エレベーター前） → GOAL：タワー2F（西武新宿駅側）。30〜45分は実地テスト前の目安です。

ST3で実レンタル・自己申告。APIなし。在庫なしは現地スタッフ案内による代替参加。8地点版とは保存キーを分離しています。回答は365 / LOCK / SAFE / MONITOR DETECT LOCK RECOVER。

参加前後の回答は本人の端末にのみ保存され、主催者へは送信されません。集計する場合は承認されたアンケートURL・同意文を確定してください。無料券は実際の配布券を使い、架空コードは表示しません。

施設情報・謎・キー・コンテ・正答はconfig.jsに集約。印刷物・画像付き絵コンテはこのデータから生成。ST1は3記号の数字化、ST2は異常スロット、ST3はレンタル＋色順、ST4は安全ログ番号の統合謎。

映像制作：ST1〜4各15秒、記号と番号は2秒以上保持、無音でも判読可。ST3は色名も併記。既存コンセプト画像は画の参考であり、今回のキーはテロップで正確に差し替える。チャポポは公式承認素材へ差し替え。

運営：ST1冊子配布、ST2の4Fアクセス確認、ST3在庫・無料券適用支援と返却枠確認、ST4ゴールと返却案内。施設許諾・設置状況・営業時間・入稿仕様・権利・無料券条件を開催前に確認。サイネージ停止は各STのキーをスタッフ掲示で代替。

安全根拠： https://chargespot.jp/topics/2444/ 、 https://chargespot.jp/topics/7588/ 、 https://chargespot.jp/battery/ （元8地点版の確認資料を継承。MVP化では新たな安全性の主張を追加していません）。

公開：既存GitHub Pagesリポジトリにmvpフォルダを追加すると /mvp/ で動作。index.html、app.js、config.js、mission.css、shinjuku-night.jpgを同じmvpフォルダへ配置してください。印刷・コンテの出力はoutput/mvp/。
