# 4地点MVP版

正答入力後は「正解！」と関連するChargeSPOTの説明を表示し、参加者が「次のステーションへ進む」（ST4は「ゴールへ進む」）を押して進みます。説明画面も保存され、再読み込みしても飛ばされません。ST1：365日IoT監視、ST2：異常時の貸出ロック・給電遮断、ST3：回収と最長3年の管理運用、ST4：安全管理の振り返りと今後の利用提案。説明はconfig.jsのpromotionsで編集できます。公式出典 https://chargespot.jp/topics/2444/ を2026年10月1日に再確認。リスクゼロの保証ではない旨と、物語と実サービスの区別を掲載しています。

START：歌舞伎町タワー2F（シネシティ広場側） → タイトーステーション新宿東口店4F → ビックカメラ新宿東口店1F（西側エレベーター前） → GOAL：タワー2F（西武新宿駅側）。30〜45分は実地テスト前の目安です。

ST3で実レンタル・自己申告。APIなし。在庫なしは現地スタッフ案内による代替参加。8地点版とは保存キーを分離しています。回答は365 / LOCK / SAFE / MONITOR DETECT LOCK RECOVER。

参加前後の回答は本人の端末にのみ保存され、主催者へは送信されません。集計する場合は承認されたアンケートURL・同意文を確定してください。無料券は実際の配布券を使い、架空コードは表示しません。

施設情報・謎・キー・コンテ・正答はconfig.jsに集約。印刷物・画像付き絵コンテはこのデータから生成。ST1は3記号の数字化、ST2は異常スロット、ST3はレンタル＋色順、ST4は安全ログ番号の統合謎。

映像制作：ST1〜4各15秒、記号と番号は2秒以上保持、無音でも判読可。ST3は色名も併記。既存コンセプト画像は画の参考であり、今回のキーはテロップで正確に差し替える。チャポポは公式承認素材へ差し替え。

運営：ST1冊子配布、ST2の4Fアクセス確認、ST3在庫・無料券適用支援と返却枠確認、ST4ゴールと返却案内。施設許諾・設置状況・営業時間・入稿仕様・権利・無料券条件を開催前に確認。サイネージ停止は各STのキーをスタッフ掲示で代替。

安全根拠： https://chargespot.jp/topics/2444/ 、 https://chargespot.jp/topics/7588/ 、 https://chargespot.jp/battery/ （元8地点版の確認資料を継承。MVP化では新たな安全性の主張を追加していません）。

公開：既存GitHub Pagesリポジトリにmvpフォルダを追加すると /mvp/ で動作。styles.cssとassets/storyboard画像は親フォルダを参照。印刷・コンテの出力はoutput/mvp/。
